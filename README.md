# Evaluate GDP forecasts with the data available then

A planning team needs a forecast comparison that survives economic data revisions. This study will compare simple GDP-growth forecasts using the historical data available at each quarterly origin and a later revised vintage. It will score both against early and revised growth estimates, keeping the two effects separate.

**Current state: protocol before data collection.** No winning model, rank reversal, improved decision or realized benefit is established. The [fixed protocol](PROTOCOL.md) sets the source, information boundary, six forecasting rules, temporal split, exclusions and checks. Source: the Philadelphia Fed's Real-Time Data Set for Macroeconomists, based on BEA releases. Separate formal-publication projects, including Azure optimization, remain private.
